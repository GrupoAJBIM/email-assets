# email-assets

Imagens hospedadas para as campanhas de e-mail do Grupo AJ.
Servidas via CDN jsDelivr.

## 20-anos (sequencia de storytelling, 5 capitulos)

| arquivo | uso | dimensao |
|---|---|---|
| `20-anos/cap1-header-desktop.png` | Cap. 1 - topo, desktop | 1200 x 600 (2:1) |
| `20-anos/cap1-header-mobile.png` | Cap. 1 - topo, mobile | 1200 x 1200 (1:1) |
| `20-anos/cap1-meio-desktop.png` | Cap. 1 - meio, desktop | 1200 x 800 (3:2) |
| `20-anos/cap1-meio-mobile.png` | Cap. 1 - meio, mobile | 1200 x 1200 (1:1) |

Base da URL:
`https://cdn.jsdelivr.net/gh/GrupoAJBIM/email-assets@main/`

## Cache

O jsDelivr mantem `@main` em cache por ate 12h. Para trocar uma arte com
efeito imediato, suba com nome novo (`-v2`) e atualize o `src` no HTML.
